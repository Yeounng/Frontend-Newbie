### What I learned

ol,ul,li 태그에 내장되어있는 기본 공통 스타일링

margin-block-start: 1em;
margin-block-end: 1em;
margin-inline-start: 0px;
margin-inline-end: 0px;
padding-inline-start: 40px;

list marker의 속성을 변경하는 li::marker pseudo elements

marker와 텍스트의 간격을 padding-inline-start로 조정하고 아이템 상하 간격은 line-height로 조정하였다.
