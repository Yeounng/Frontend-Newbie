### What I learned

- media screen을 사용할때 큰폭에서 작은폭 순서로 코딩해야 작아졌을때 값이 override돼서 정상적으로 적용된다.
- text-wrap 속성을 사용해보기
- max-inline-size를 사용해 현재 폰트사이즈에서 몇번째 글자에서 줄바꿈을 시행할지 결정할 수 있다.
- 할인 전 가격을 표시하기 위해 data속성과 ::before pseudo element를 사용해보았다.
- font-size에서 rem 사용
- max-widht와 vw, %를 사용해 반응형디자인에 대비하였다
- background-image를 사용하지 않고 html에 img src로 적용된 이미지를 css에서 content: url() 속성으로 변경해 코딩해보았다.
